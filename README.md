## DXF creator for kompas-3d
For version 0.4.1

### Описание и назначение
Макрос предназначен для ускоренного создания разверток в формате dxf из деталей kompas-3d (формат m3d).

### Инструкция по работе с макросом
1. Для начала работы убедитесь, что kompas-3d запущен.
2. Запустите программу dxf_creator.exe.
3. Макрос предусматривает два способа создания dxf файлов. Одиночный и пакетный.
4. Для одиночного способа создания:
- Откройте деталь в программе kompas-3d для которой надо создать dxf файл.
- Нажмите кнопку "Создать dxf". Если предварительно выделить плоскую поверхность, то dxf создастся по этой поверхности.
- dxf файл появится в той же папке где находится исходная модель.
5. Для пакетного создания dxf:
- Выберете и перенесите все файлы (drag and drop), для которых необходимо создать dxf развертки в окно макроса.
- Нажмите кнопку "Создать группу dxf".
- Дождитесь окончания операции. По окончанию операции появится надпись "Готово".

### Особенности работы
- Макрос DXF creator for kompas-3d проверялся только с kompas-3d v24 for windows. Скорее всего не будет работать на версии ниже v23.
- Имя dxf файла формируется следующим образом {имя_детали}{номер_исполнения}{толщина_листа}.
- Толщина для листовой детали берется из свойств.
- Толщина обычной детали берется по наименьшему размеру габарита. И габарит определяется относительно плоскосте основной системы координат.
- При автоматическом выборе поверхности относительно которой будет построена развертка, берется наибольшая плоская поверхность.
- Деталь для которой делается развертка должна быть сохранена.
- Качество получившегося dxf файла от данного макроса не зависит. Преобразование делается внуренними инстрментами kompas-3d.
